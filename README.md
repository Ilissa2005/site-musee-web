# Site Web - Gestion de Musée

## Description

Ce projet a été réalisé dans le cadre de ma formation en Licence 2 Informatique.

Il s’agit d’une application web de gestion de musée comprenant deux parties principales :

- **Front Office** : présentation des œuvres, des artistes et des informations du musée.
- **Back Office** : gestion et administration des contenus.

Le projet final est terminé et disponible dans le fichier `.zip` du dépôt.  
Les fichiers présents séparément dans le dépôt correspondent à une première étape du projet et ne représentent pas la version finale complète.

---

## Version finale du projet

Pour consulter le code complet, la structure finale et la logique globale du projet, il faut télécharger le fichier `.zip` disponible dans ce dépôt.

Ce fichier contient la version complète du site avec l’ensemble des fonctionnalités développées.

---

## Fonctionnalités principales

- Présentation des œuvres du musée
- Présentation des artistes
- Pages dynamiques en PHP
- Gestion des contenus via un Back Office
- Utilisation d’une base de données SQL
- Formulaires de gestion et d’administration
- Sessions utilisateur
- Cookies
- Protection des formulaires avec token CSRF
- Organisation du projet en plusieurs dossiers
- Séparation entre affichage, logique et données

---

## Technologies utilisées

- HTML5
- CSS3
- JavaScript
- PHP
- SQL
- Base de données
- Sessions
- Cookies
- Token CSRF

## Objectifs pédagogiques

Ce projet m’a permis de mettre en pratique plusieurs compétences :

- Concevoir une application web structurée
- Organiser un projet avec Front Office et Back Office
- Manipuler des données dynamiques avec PHP et SQL
- Gérer des formulaires et des contenus
- Mettre en place des mécanismes de sécurité web
- Utiliser les sessions, les cookies et la protection CSRF
- Comprendre la logique d’une application web complète

---

## Sécurité

Une attention particulière a été portée à la sécurité de l’application :

- gestion des sessions utilisateur ;
- utilisation de cookies ;
- protection des formulaires avec un token CSRF ;
- séparation des rôles entre utilisateur et administration ;
- sécurisation des accès aux pages du Back Office.
