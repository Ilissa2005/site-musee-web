#  Site Web - Gestion de Musée

##  Description

Ce projet a été réalisé dans le cadre de ma formation en informatique.

Il s’agit d’une application web de gestion de musée comprenant :

     * Front Office : présentation des œuvres et des artistes

    * Back Office : gestion et administration des contenus

Le projet est développé en HTML, CSS et PHP et est actuellement en cours d’amélioration.
---

##  Fonctionnalités

*  Présentation des œuvres du musée
*  Présentation des artistes
*  Informations sur le musée
*  Navigation entre différentes pages
*  Gestion basique des contenus

---

##  Technologies utilisées

* HTML5
* CSS3
* PHP

---


##  Objectifs pédagogiques

* Concevoir un site web structuré
* Organiser un projet web
* Comprendre la gestion de contenu côté utilisateur

 Projet en cours d’amélioration :
